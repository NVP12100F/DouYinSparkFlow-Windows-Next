# 🔥 DouYin SparkFlow — Windows 绿色版

**抖音多账号"续火花"自动维护工具 · Windows Portable Build**

解压即用，**无需安装 Python / Node.js / Docker / WSL2**。自动给指定好友发送私信，维持每日互动火花。

> ⚠️ **免责声明**：本工具仅供学习研究使用，请遵守平台规则、合理低频使用。使用本工具产生的一切后果（含账号异常、封禁）由使用者自行承担。建议先用小号测试。

---

## 📦 环境要求

- Windows 10 / 11（64 位）
- 无任何运行时依赖（Python、Node.js、Docker、WSL2 均不需要）
- 首次使用需要能用手机抖音 App 扫码

## 📁 目录结构

```
DouYinSparkFlow-win64/
├── start.bat               # 一键启动（推荐入口）
├── stop.bat                # 停止后台服务
├── README.md               # 本文件
├── app/                    # 主程序与全部运行数据（exe 旁）
│   ├── sparkflow.exe       #   Web 控制台（:8787）+ 发送任务
│   ├── cron-runner.exe     #   调度器（定时触发任务）
│   ├── login-desktop.exe   #   登录服务（:18090，本机扫码窗口）
│   ├── config.json         #   运行配置（发送窗口等，自动生成）
│   ├── usersData.json      #   账号/好友/发送账本（敏感！）
│   ├── state/              #   调度 spool / 浏览器 Profile
│   └── logs/               #   运行日志（ops.log / scheduler.log）
├── chrome/                 # 内置 Chromium（约 500 MB，勿删）
└── node/                   # 内置协议发送器 protocol-sender.exe
```

## 🚀 快速开始

1. 双击 **`start.bat`**（自动启动调度器与登录服务，前台运行 Web）。
2. 浏览器打开 **`http://127.0.0.1:8787`**。
3. 首次访问：**初始化管理员账号**（用户名 + 密码）→ 登录进入控制台。
4. 依次完成以下配置后，工具就会按窗口自动发送：

| 步骤 | 操作位置 | 说明 |
|---|---|---|
| ① 添加账号 | 首页「交互式登录浏览器」→「添加新的抖音账号」 | 本机弹出浏览器窗口 + 页面二维码，**手机抖音扫码** →「保存新账号登录」 |
| ② 刷新好友 | 账号卡片 → 好友选择器 →「刷新好友」 | 抓取"朋友私信"列表（需登录态有效） |
| ③ 选择目标 | 好友选择器勾选 或 文本框手填昵称（每行一个）→「保存账号」 | 只对列表内好友发送 |
| ④ 启用账号 | 账号卡片「启用自动续火花」 | 未启用不参与任务 |
| ⑤ 设置窗口 | 首页底部「运维操作」→「自动发送窗口」→ `10:00-18:00/20m` →「更新发送窗口」 | 起时:00-止时:00/间隔分钟，整点 |

## ⏰ 定时任务：设置与确认

- **设置**：首页 → 运维操作 → 自动发送窗口（如 `10:00-18:00/20m` = 每天 10:00–18:00 每 20 分钟一次）。
- **原理**：Web 写入 `app\config.json` + `app\state\cron\root`，由 `cron-runner.exe` 每分钟检查、到点执行 `sparkflow.exe --doTask`。
- **确认生效**：
  1. 首页概览「下次自动触发」显示具体时间；
  2. `app\state\cron\root` 有 3 行 `…sparkflow.exe --doTask…` 命令；
  3. 到点后 `app\logs\scheduler.log` 出现 `run: …`，`app\logs\ops.log` 出现任务日志。

## 🎯 手动任务按钮（均有确认弹窗）

| 按钮 | 位置 | 行为 |
|---|---|---|
| 补发全部对象 | 首页顶部 | 无视窗口，全部账号全部目标强制发一轮（慎用） |
| 补发异常 | 首页 / 发送控制台 | 只补发待核验、失败、受账号异常影响的目标 |
| 补发待发送 | 发送控制台顶部 | 只补发今日未强确认且可重试的目标（最安全的兜底） |

> 「强确认」：消息发出后需拿到服务端回执或页面回显证据才算"已发"；证据不足的目标记为待核验，下一轮调度会重新发送（防漏发优先）。

## ❓ 常见问题

- **登录页里的桌面画面显示 502？** 可忽略。那是 Docker 版的 noVNC 远程桌面地址，Windows 版没有该功能。**Windows 登录方式：点「添加新的抖音账号」→ 本机弹窗 + 页面二维码 → 手机扫码 →「保存新账号登录」**。
- **登录窗口打不开 / 没反应？** 确认 `login-desktop.exe` 在运行；空闲 30 分钟自动退出是正常行为，重新点按钮即可。
- **「刷新好友」失败？** 抖音页面改版会导致抓取失败，直接在「目标好友」文本框手填昵称即可，不影响发送。
- **任务失败提示「登录失效」？** 在该账号卡片点「重新登录」重新扫码。
- **Windows 提示安全风险 / 无法运行？** 未签名程序可能被 SmartScreen/杀软拦截，选择"仍要运行"或加入白名单。
- **今天发过了还会再发？** 未拿到强确认的目标会被重试（设计如此）。

## 💾 数据与迁移

- 所有数据（账号、目标、账本、配置、日志）都在 `app\` 下，**备份/迁移 = 复制整个目录**。
- 重置全部状态：删除 `app\state`、`app\config.json`、`app\usersData.json`、`app\webui_settings.json`（会要求重新初始化管理员）。
- 升级：替换 `app\`（exe 与运行库），保留 `app\state`、`app\config.json`、`app\usersData.json` 即保留全部数据；`chrome\`、`node\` 按版本说明决定是否替换。

## 🔁 重启电脑后

1. 如上次未停干净：双击 `stop.bat`。
2. 双击 `start.bat` → 打开 `http://127.0.0.1:8787` 登录。
3. 配置无需重做，账号与目标仍在。

## 📋 已知限制

- 好友列表刷新依赖抖音创作者中心页面结构，改版后可能失败（可用手动填写替代）。
- 多账号顺序发送（默认并发 1）；请合理设置发送窗口，避免高频操作。
- 协议发送路径（`useProtocolSender`）默认关闭，走浏览器发送，更稳妥。
- 本包仅供学习研究，风险自担。
