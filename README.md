# DouYin SparkFlow Windows 绿色版

一个基于 douyin-sparkflow 修改的 Windows 便携版。

目标：
让不会配置 Python 环境的 Windows 用户也可以快速运行。

## ✨ 特性

- ✅ Windows 绿色版
- ✅ 无需安装 Python
- ✅ 双击启动
- ✅ 内置 Web 管理界面
- ✅ 支持账号管理
- ✅ 支持任务调度
- ✅ 自动保存运行状态
- ✅ 独立数据目录

## 📦 使用方法

1. 下载 Release 中的 zip
2. 解压到任意目录
3. 运行 start.bat
4. 打开浏览器访问：

http://127.0.0.1:8787

5. 初始化管理员账号

## 🖥️ 系统要求

Windows 10/11 64位

## ⚠️ 注意

首次运行需要登录账号。
请合理使用自动化功能。
